# Rules

L'entrée **Rules** du menu principal ouvre une seule note personnelle, commune à toutes tes dates et tous tes types de journée.

Le texte enregistré s'affiche aussi sur le dashboard, juste au-dessus de **⚔️ Tableau des Primes (Aujourd'hui)**. Les retours à la ligne sont conservés ; une note vide n'affiche rien à cet endroit.

Écris tes repères dans le champ, puis clique **Enregistrer**. Le compteur indique le nombre de caractères, avec une limite de **500**, retours à la ligne compris. Pour effacer la note, enregistre un champ vide.

La note est conservée sur le serveur pour ton compte et retrouvée après rechargement ou sur un autre appareil connecté au même compte. Chaque compte possède sa propre note. Les modifications en cours restent à enregistrer ; si la sauvegarde échoue, la saisie reste dans le champ pour réessayer.

Rules est du texte simple, sans effet sur les quêtes, le score, l'XP ou les streaks.
